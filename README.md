🛋️ CozyHaven – E-Commerce Website

CozyHaven is a modern e-commerce frontend website where users can browse products, view details, and filter items by category with a clean UI and smooth interactions.

🌐 Live Demo

🔗 CozyHaven Live
 (https://fancy-pavlova-45c3bb.netlify.app/)

✨ Features
🛒 View Products – Explore a variety of products with images and details.
🔎 Product Details – Click on any item to see detailed information.
🏷️ Category Filter – Filter products by categories:
All Products
Cloting
Hoodies
Shoe
Bag
📱 Responsive Design – Fully optimized for desktop, tablet, and mobile.

🛠️ Tech Stack
Frontend: React.js
Styling: Tailwind CSS
Deployment: Netlify
